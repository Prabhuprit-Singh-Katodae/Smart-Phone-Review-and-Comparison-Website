# Product photos

The catalogue cards and detail pages use model-specific product photos loaded from the manufacturer, retailer, or technology publication listed beside each image on the detail page. An internet connection is required for these images to load. Image hosts can change or block external embedding over time.

The “Phone A”, “Phone B”, and “Phone C” entries in the admin area are fictional wireframe examples, so they do not correspond to real phone models and do not have model-specific photos.

To use local image files later, download or license each image appropriately, place it in an `images/` folder, and update the `PHOTOS` URLs in `script.js` to local file paths.
